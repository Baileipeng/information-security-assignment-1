# 关卡 2：交叉测试（与其他小组程序核对算法一致性）

## 一、关卡要求

与其他小组交换测试数据（若干组 密钥 K、明文 P 及其密文 C），
用本程序计算同样的输入，核对结果是否完全一致，验证双方实现正确。

## 二、代码文件

| 文件 | 说明 |
|------|------|
| `main.cpp` | 本关卡独立示例程序（参考向量表 / 回归校验 / 批量核对 三种模式） |
| `CMakeLists.txt` | 单独构建本关卡的构建脚本 |
| `../src/sdes.h` / `../src/sdes.cpp` | S-DES 核心算法 |

## 三、编译与运行

```bash
./build_levels.sh                 # 或 cmake -B build -G Ninja && cmake --build build
```

```bash
./level2_cross_test               # 模式一：输出 20 组参考向量表
./level2_cross_test verify        # 模式二：与内置期望值逐行比对（回归测试）
./level2_cross_test stdin         # 模式三：从标准输入批量核对
echo "1010000010 00101000" | ./level2_cross_test stdin
```

## 五、实测结果

```
共 20 组向量：通过 20 组，失败 0 组 —— [PASS] 与标准结果完全一致
附加检查：P=00101000 在 1024 个密钥下的密文取值个数 = 101 个
          （<256 说明存在多密钥映射，详见关卡 5）
```
